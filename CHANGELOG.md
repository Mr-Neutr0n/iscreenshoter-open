# Changelog

- Make screenshot history opt-in and bound retained captures by age, count and size.
- Separate removal from history from moving exported files to Trash.
- Downsample history thumbnails and limit rendered history views.

- Isolate verification and generated demos from real history and preferences.
- Build in a fresh staging directory and record source and toolchain metadata.
- Add macOS CI, tagged release packaging, checksums and artifact attestations.
- Document security reports, contribution rules, installation, removal and manual acceptance checks.
