# Resource provenance

The Swift implementation, resource generator, generated artwork, documentation,
and synthetic demo content in this repository are released under MIT.

This repository contains no iScreen Shoter executables, extracted asset catalogs,
original icons, original sticker files, interface archives, decompiled listings,
or license data. The public build uses independently drawn geometric icons and
stickers, generated by `scripts/generate-resources.swift`.

The app uses Apple's AppKit, SwiftUI, Vision, ScreenCaptureKit, AVFoundation,
Carbon, and ServiceManagement frameworks supplied by macOS. It renders system
fonts and emoji through macOS. These system components remain subject to Apple's
terms and are not included in the MIT grant.

The name iScreen Shoter is used to identify the app that inspired this independent
implementation. This project is not affiliated with, endorsed by, or an official
open-source release of that app.
