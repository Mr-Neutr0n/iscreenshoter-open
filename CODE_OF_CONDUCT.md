# Community conduct

Treat contributors and users with respect. Discuss the code and behavior. Do not
harass, threaten, insult, discriminate, post private information, or send sexual
content. Keep issues and pull requests relevant to the project.

The maintainer can edit or remove content, close discussions, and restrict
participation when needed. Repeated or severe violations can lead to a ban.
Maintainer decisions should use the same standards for all participants.

For a conduct concern, contact repository owner
[Mr-Neutr0n](https://github.com/Mr-Neutr0n) through a contact channel on that
profile. If no private channel is listed, request one in a short issue without
posting private details. This volunteer project cannot promise confidentiality
for information posted publicly or a specific response time.
